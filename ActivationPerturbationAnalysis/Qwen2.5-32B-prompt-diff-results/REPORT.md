# Qwen2.5-32B-Instruct 激活扰动分析报告

## 1. 实验概述

### 1.1 实验目标

测量在真实 agent 多轮对话场景中，**某一中间对话轮次的存在/缺失**如何影响后续内容在 Transformer 各层的隐藏状态表示。

### 1.2 模型与数据

| 项目 | 值 |
|------|-----|
| 模型 | Qwen2.5-32B-Instruct（65 层：1 embedding + 64 transformer） |
| 精度 | bfloat16 |
| 数据来源 | Langfuse trace 导出的真实 subagent 对话链（85 条前缀链，1085 条 prompt） |
| 实验方法 | Triplet 三元组比较 |
| 完成实验数 | **761 个 triplet**（168 个因 OOM 等原因失败，40 个被跳过） |
| 总测量记录 | 1,343,355 条 |

### 1.3 实验方法：Triplet 三元组比较

对于 subagent 的连续三条前缀链 prompt P_k ⊂ P_{k+1} ⊂ P_{k+2}：

```
P_k     = [prefix]
P_{k+1} = [prefix][D1]           ← D1：第 k+1 轮新增内容（assistant 回复 + tool 返回）
P_{k+2} = [prefix][D1][D2]       ← D2：第 k+2 轮新增内容
```

构造两条序列送入模型：

```
seq_full = [prefix][D1][D2]       ← 自然完整序列（D1 存在）
seq_skip = [prefix][D2]            ← 人工删除 D1（直接拼接）
```

**度量**：D2 区域中对应位置 token 的 hidden state cosine similarity。
similarity = 1.0 表示 D1 无影响；偏离 1.0 越多，D1 的影响越大。

### 1.4 实验数据特征

| 统计项 | 均值 | 中位数 | 最小值 | 最大值 |
|--------|------|--------|--------|--------|
| 总上下文长度（P_{k+2}） | 9,401 tokens | 6,936 | 451 | 33,509 |
| D1 长度（"扰动"） | 1,395 tokens | 897 | 28 | 24,398 |
| 共享前缀长度（prefix） | 6,639 tokens | 4,158 | 245 | 29,244 |

## 2. 核心发现

### 2.1 D1 对后续内容产生了显著且持久的影响

**全局统计（immediate 桶，D2 起始 10 个 token）**：

- 整体平均 cosine similarity = **0.951**（偏离 1.0 约 5%）
- 最低平均 similarity 出现在 Layer 39 = **0.878**（偏离 12.2%）
- 极端 case 的 min similarity 低至 **0.219**（接近正交）

结论：**即使在 causal attention 架构下，删除一段中间对话轮次会对后续内容的隐藏状态产生实质性改变。D1 不仅仅是"经过的上下文"——它通过 attention 机制持续塑造后续 token 的表示。**

### 2.2 影响呈明显的"层深度 U 型曲线"

以 D2 起始 10 个 token（immediate 桶）的平均 similarity 为例：

```
Layer 深度        平均 Similarity    偏离程度
───────────────────────────────────────────────
Embedding (L0)        1.0000         ≈0%     ← 纯 token embedding，不受影响
Early (L1-8)          0.9811         ~2%     ← 轻微影响
Early-Mid (L9-16)     0.9626         ~4%     ← 影响递增
Mid (L17-32)          0.9178         ~8%     ← 影响加深
Mid-Late (L33-48)     0.8847        ~12%     ← 影响最大 ★
Late (L49-60)         0.9163         ~8%     ← 开始恢复
Final (L61-64)        0.9330         ~7%     ← 部分恢复但不完全
```

**关键模式**：
- **影响"谷底"在 Layer 37-45**（similarity 降至 0.878-0.886），对应模型的中高层
- 最后几层出现 **部分恢复**（similarity 回升至 0.93），但最终输出层 L64 又微降至 0.912
- 这提示模型在中间层进行了最深度的上下文整合，而高层有一定的"归一化/压缩"作用

### 2.3 第一个 D2 token 受冲击最大，随后快速恢复

D2 区域第一个 token（offset=0）的 similarity 显著低于后续 token：

```
Layer     t0     t1     t2     t3     t4     t5     ...t9
────────────────────────────────────────────────────────
L0     1.0000 1.0000 1.0000 1.0000 0.9982 0.9978  0.9999
L16    0.7961 0.9626 0.9578 0.9483 0.9698 0.9781  0.9823
L32    0.7343 0.8409 0.9314 0.9027 0.9142 0.9266  0.9365
L40    0.7359 0.7799 0.9310 0.9098 0.8976 0.9169  0.9183
L48    0.8018 0.8199 0.9122 0.9183 0.9074 0.9120  0.9238
L64    0.9423 0.8957 0.8506 0.9332 0.9137 0.9063  0.9290
```

**关键模式**：
- **Mid 层（L24-L40）的 t0 跌至 0.67-0.74**，这意味着 D1 边界处的第一个 D2 token 在这些层的表示被彻底改变
- 恢复在 2-3 个 token 内迅速发生（t0→t2 从 0.73 跳到 0.93）
- **但恢复不完全**：即使在 t9，similarity 仍在 0.92-0.94 左右，没有回到 1.0
- L64（最终输出层）呈现异常模式：t0=0.94 但 t2 反而跌至 0.85，暗示高层有延迟反应

### 2.4 影响具有长程持久性，不会随距离完全消退

从 periodic 桶分析 D2 内不同偏移位置的 similarity：

```
距 D1 边界的偏移    L0        L16       L32       L40       L48       L64
──────────────────────────────────────────────────────────────────────
offset=0          1.0000    0.9540    0.8982    0.8832    0.8938    0.9119
offset=500        0.9998    0.9954    0.9750    0.9506    0.9330    0.9611
offset=1000       0.9998    0.9972    0.9812    0.9565    0.9389    0.9620
offset=2000       0.9998    0.9977    0.9833    0.9593    0.9419    0.9641
offset=5000       0.9995    0.9990    0.9930    0.9757    0.9609    0.9793
offset=10000      0.9999    0.9996    0.9986    0.9945    0.9894    0.9950
```

**关键发现**：
- **500 token 内快速恢复**：从 immediate 到 offset=500，similarity 有大幅跃升（最明显的 L32：0.898→0.975）
- **500-2000 token 趋于平台**：恢复速度急剧放缓，进入"长尾"阶段
- **5000+ token 仍有可测量差异**：L48 在 offset=5000 处仍为 0.961（偏离 4%），而非 1.0
- **10000 token 后基本收敛**：所有层的 similarity 均在 0.99 以上
- **L48 始终是"长尾效应"最顽固的层**：在每个距离阈值上都是恢复最慢的

结论：**D1 的影响分两阶段衰减——前 500 token 快速恢复，然后进入缓慢的长尾衰减，约在 5000-10000 token 后才趋近消失。**

## 3. 影响因素分析

### 3.1 上下文长度的影响

按总上下文长度分组（immediate 桶，全层平均）：

| 上下文长度 | 平均 Similarity | 标准差 | 实验数 |
|-----------|-----------------|--------|--------|
| < 2K tokens | 0.889 | 0.038 | 140 |
| 2-5K tokens | 0.909 | 0.036 | 172 |
| 5-10K tokens | 0.933 | 0.026 | 172 |
| 10-20K tokens | 0.944 | 0.026 | 178 |
| 20-40K tokens | 0.954 | 0.028 | 99 |

**发现**：短上下文（<2K）中 D1 的影响反而更大（similarity 更低）。这可能是因为：
1. 短序列中 D1 占总长度比例更大
2. prefix 较短时，D2 更依赖 D1 提供的上下文信息

### 3.2 D1 相对大小的影响

按 D1 占总长度的比例分组：

| D1 比例 | 平均 Similarity | 标准差 | 实验数 |
|---------|-----------------|--------|--------|
| < 5% | 0.925 | 0.025 | 135 |
| 5-10% | 0.935 | 0.030 | 172 |
| 10-20% | 0.940 | 0.033 | 191 |
| 20-30% | 0.924 | 0.042 | 134 |
| 30-50% | 0.902 | 0.042 | 89 |
| 50-100% | 0.863 | 0.028 | 40 |

**发现**：D1 占比越大，影响越强。当 D1 超过总长度 30% 时，similarity 显著下降。但 D1 占比 <5% 时 similarity 也非最高（0.925 vs 0.940），提示**影响并非简单线性**——极小的 D1 也能产生不可忽视的影响。

### 3.3 D1 绝对大小与 similarity 的相关性

Pearson 相关系数（D1 token 数 vs immediate similarity）= **+0.145**

相关性较弱且为正值（看似反直觉），原因是 D1 绝对长度与上下文长度高度相关——更长的 D1 通常意味着更长的总序列，而 3.1 显示长序列的 similarity 反而更高。**相对比例（3.2）才是更有意义的指标。**

## 4. 极端案例分析

### 4.1 最低 similarity 案例

| Layer | Experiment | min_similarity | 上下文 | D1 长度 | Prefix |
|-------|------------|---------------|--------|---------|--------|
| L46 | 8ab573e7 | **0.219** | 1,356 | 347 | 261 |
| L46 | 0cf14640 | **0.230** | 3,299 | 1,401 | 254 |
| L45 | 8ab573e7 | **0.238** | 1,356 | 347 | 261 |
| L46 | a5feecdf | **0.241** | 4,158 | 1,375 | 268 |

**共同特征**：
- 集中在 **Layer 43-47**
- **prefix 很短**（245-307 tokens），即共享前缀很少
- D1 占比较高
- 短 prefix + 大 D1 = D2 几乎完全依赖 D1 提供上下文 → 删除 D1 后表示剧变

### 4.2 窗口内变异性

immediate 桶的 std_similarity（同一 10-token 窗口内不同 token 的 similarity 波动）：

| Layer | 平均 std | 最大 std |
|-------|---------|---------|
| L0 | 0.0019 | 0.0046 |
| L16 | 0.0594 | 0.1436 |
| L32 | 0.0732 | 0.1885 |
| L40 | 0.0809 | 0.1934 |
| L48 | 0.0612 | 0.1914 |
| L64 | 0.0545 | 0.1973 |

变异性在 L40 最高，与 mean similarity 最低的层一致。最大 std 接近 0.2，说明同一个短窗口内有的 token 可能接近 1.0 而有的低至 0.6。

## 5. 实验完整性

| 项目 | 数值 |
|------|------|
| 应执行 triplet 数 | ~969（估算） |
| 成功完成 | 761 (78.5%) |
| 失败（OOM 等） | 168 (17.3%) |
| 跳过（前缀链验证失败等） | 40 (4.1%) |

失败主要集中在序列较长的 triplet（seq_full + seq_skip 的 attention 超出 GPU 显存限制）。这意味着 **最长序列的结果缺失**，实际的长程影响可能被低估。

---

## 6. 结论

### 6.1 核心结论

1. **中间对话轮次对后续内容的影响是实质性的**：平均 cosine similarity 仅为 0.951（immediate）/ 0.932（全 D2 区域），远非 1.0。
2. **影响呈"层深度 U 型"分布**：中高层（L37-45）受影响最大（similarity 低至 0.878），浅层和深层较轻。
3. **影响具有长程持久性**：快速恢复发生在前 500 token，但 5000 token 后仍有 4% 的偏离，约 10000 token 后才基本消失。
4. **首 token 冲击效应**：D2 的第一个 token 受影响最大（中间层 similarity 低至 0.67），2-3 个 token 内快速但不完全恢复。
5. **短上下文更脆弱**：prefix 越短、D1 占比越大，影响越强烈。

### 6.2 对 Agent 系统设计的启示

- **上下文压缩有风险**：如果在多轮对话中删除或压缩中间轮次，后续内容的模型内部表示会发生显著变化，可能导致输出质量下降。
- **中间层是信息整合的核心**：Layer 37-48 是 Qwen2.5-32B 进行深度上下文理解的关键区域，对上下文变化最敏感。
- **长对话链的"遗忘"约在 5000-10000 token 后才趋近**：在此范围内，早期轮次的影响仍然可测量。
- **系统设计应考虑渐进式影响**：D1 的影响不是"全有或全无"，而是幂律衰减；越靠近 D1 的 D2 内容受影响越大。
